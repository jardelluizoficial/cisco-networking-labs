# Cisco Networking Labs

Laboratórios de redes desenvolvidos durante meus estudos na Cisco Networking Academy, com registros das configurações, testes e soluções aplicadas no Cisco Packet Tracer.

## Laboratórios

| Laboratório | Conteúdos praticados | Status |
| --- | --- | --- |
| [Rede doméstica com roteador sem fio](rede-domestica-packet-tracer/README.md) | Cabeamento, DHCP, gateway, Wi-Fi 2,4 GHz e WPA2 Personal | Concluído |
| [Conectar-se a um servidor Web](conexao-servidor-web-packet-tracer/README.md) | Conectividade IP, ping (ICMP) e acesso Web por endereço IP (HTTP) | Concluído |

## Objetivo

Desenvolver fundamentos de redes e documentar minha evolução prática na preparação para uma oportunidade em suporte de TI.

Os cenários deste repositório são simulações de estudo. Cada laboratório apresenta o objetivo, as configurações realizadas e as evidências disponíveis.
